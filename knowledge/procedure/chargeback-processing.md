# Chargeback Processing Procedure

**Access:** Risk personnel only

## Overview

This procedure defines how card chargebacks are initiated, represented, and resolved under network rules, ensuring correct assignment of liability.

## Eligibility

- Applies to eligible card disputes routed from dispute resolution.
- The transaction must fall within the network's chargeback time limits.

## Procedure Steps

1. Validate the dispute qualifies for a chargeback reason code.
2. Assign the appropriate network reason code.
3. Submit the chargeback within the network time limit.
4. Await merchant representment and evidence.
5. Evaluate representment against the original dispute.
6. Escalate to pre-arbitration or arbitration if warranted.
7. Post the final liability decision to the customer's account.

## Reason Code Categories

| Category | Examples |
|----------|----------|
| Fraud | Card-not-present, counterfeit |
| Authorization | No authorization, expired |
| Processing error | Duplicate, incorrect amount |
| Consumer dispute | Not as described, not received |

## Recordkeeping

Retain chargeback correspondence and evidence per the retention schedule.

## Disclosures

Outcomes are communicated to the customer consistent with the dispute resolution procedure.
