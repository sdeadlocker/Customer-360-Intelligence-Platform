# Screenshots

Product screenshots referenced by the top-level `README.md`. Drop PNGs here with the exact names
below and they render automatically on GitHub. Capture them from a running instance
(`npm run dev:api` + `npm run dev:web`, then http://127.0.0.1:5173).

| File | What to capture |
|---|---|
| `login.png` | The role-based sign-in screen. |
| `search-landing.png` | The search landing page with the universal "Ask anything" panel and customer search. |
| `opportunity-pipeline.png` | The revenue opportunity pipeline (identified/capturable/realized, by play) and/or the Money-in-Motion feed. |
| `dashboard-compact.png` | The 360 dashboard in **Compact** view (all cards, at-a-glance). |
| `ask-cohort.png` | Ask AI answering a book-level cohort question (e.g. "high risk customers"). |
| `ask-thread.png` | A multi-turn Ask AI conversation with follow-ups. |
| `risk.png` | The risk intelligence card with band, alerts and compliance flag. |
| `offers.png` | Ranked offers with rationale and suppression. |
| `relationships.png` | The relationship / household graph. |
| `reports-briefing.png` | The Reports panel showing the branded 360 PDF pack and the prepare-for-meeting briefing options. |
| `export.png` | The dashboard data / PDF export action. |

Recommended: 1600px wide, PNG, light theme, no real customer data (the seeded synthetic dataset is
fine and contains no real PII).
